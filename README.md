# BizInsight

BizInsight is a business intelligence and management platform for small businesses.

## Setup

1. Create a virtual environment: `python3 -m venv venv`
2. Activate the virtual environment: `source venv/bin/activate` (or `venv\Scripts\activate` on Windows)
3. Install requirements: `pip install -r requirements.txt`
4. Run the app: `flask run` (or `python -m backend.app`)
